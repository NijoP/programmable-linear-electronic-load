1 Abstract

This document presents the first-pass engineering design of a programmable linear DC electronic load
intended as a compact laboratory test instrument for DC power sources and batteries. The product
receives electrical power from an external DC source and electronically controls the amount of current
absorbed by a MOSFET power stage. The project does not use a DC–DC converter, an AC–DC
converter, an inverter, solar-energy conversion, or an Internet-of-Things subsystem.
The proposed prototype is designed for a nominal input range of 10–15 V, a controlled current range
of approximately 0.1–2 A, and a maximum electrical loading target of 30 W. Four BUZ11 N-channel
power MOSFETs are used in parallel and operated in the linear region so that the input electrical
power is intentionally dissipated as heat. Current is sensed using a 0.01 Ω shunt and an INA180A3
current-sense amplifier with a nominal gain of 100 V/V. A 12-bit MCP4725 DAC generates the
commanded current reference. An LM358B analog feedback stage performs the fast current regulation,
while an ESP32-WROOM-32 module, soldered directly onto the custom two-layer PCB, provides the
user interface, measurement, supervisory logic, protection logic, and display control.
The user operates the instrument using a rotary encoder, push buttons, and an OLED display. The
proposed operating modes are constant current, constant power, and constant resistance. A battery
discharge and capacity-test application can also use the same hardware. The design intentionally uses
moderate current and power so that the high-current paths are practical on a two-layer PCB. The
most important physical validation tasks are MOSFET linear safe-operating-area verification, thermal
characterization, control-loop stability testing, current-sensing calibration, and verification of the exact
components purchased from the selected supplier.

2 Introduction

A DC source such as a laboratory power supply or battery must often be tested under a known electrical
load. A conventional resistor can provide a load, but its current is determined by Ohm’s law and
changes directly with source voltage. A rheostat allows manual adjustment of the resistance, but it
still requires the operator to make changes when the source operating point changes.
A programmable electronic load is an active power sink. It uses a power semiconductor as a controllable
element and feedback to produce a desired current or power characteristic.
The proposed project is therefore an instrumentation-oriented power-electronics product. The power
stage consists of MOSFETs operating in their linear region. The controller and measurement subsystem
is implemented with an ESP32-WROOM-32 mounted directly on the PCB. The final PCB is intended
to look like a self-contained laboratory instrument rather than a development-board assembly.

7 End-to-End Workflow

7.1 Step 1: Apply External DC Power

The input is supplied by an external regulated or laboratory DC supply.
The target design range is

                                        VIN = 10 − −15 V.                (10)

The preferred initial development source is a current-limited laboratory power supply or an equivalent
regulated adapter capable of at least 2 A.

7.2 Step 2: Connect the Source to the PCB

The positive source terminal is connected to the PCB input positive terminal and the negative source
terminal is connected to the PCB input negative terminal.
The electrical path is intentionally routed through the main current shunt and MOSFET power stage.

7.3 Step 3: Turn on the Product

The ESP32 starts in a safe state. The MOSFET command defaults to zero so the load remains
effectively disabled until the system completes its self-check.

7.4 Step 4: User Selects a Mode
The user selects one of the following:

   a. CC: constant current;
   b. CP: constant power;
   c. CR: constant resistance.

7.5 Step 5: User Enters the Setpoint

The rotary encoder is rotated to change the desired value. Pressing the encoder confirms the selection.
Examples are:

7.6 Step 6: Reference Generation
The ESP32 writes the setpoint to the MCP4725 DAC. The DAC creates the analog control reference.

7.7 Step 7: Closed-Loop Regulation

The current-sense circuit measures the actual load current. The LM358B compares the desired reference
against the measured current and adjusts the MOSFET gate command.

7.8 Step 8: Power Absorption

The MOSFETs operate in the linear region and dissipate the source power as heat.

32 Two-Layer PCB Design                                                (123)

The project uses a two-layer FR-4 PCB.
The layout should be divided into:

   1. user-interface region;
   2. ESP32 and low-voltage electronics region;
   3. current-sensing and analog-feedback region;
   4. MOSFET power region;
   5. input and shunt region.

The current rating is only

                                                          IMAX = 2 A,
which is moderate for a properly designed two-layer PCB.
The principal routing rules are:

   • use wide copper for the main current path;
   • keep the current path short;
   • avoid narrow trace necks;
   • use copper pours where appropriate;
   • use via stitching if current changes layers;
   • route Kelvin sense lines separately;
   • keep the ESP32 and ADC area away from noisy power-node regions;
   • provide sufficient copper beneath thermal components.

37 Firmware State Machine

A simple state machine is proposed:

   1. POWER ON;
   2. SELF TEST;
   3. STANDBY;
   4. SETTING;
   5. ACTIVE;
   6. FAULT;
   7. RESET.

In POWER ON and SELF TEST states, the load command remains zero.
During SETTING, the user selects the operating mode and setpoint.
During ACTIVE, the ESP32 reads the sensors, computes the commanded current, updates the DAC,
updates the OLED, and executes the protection rules.
During FAULT, the command is forced to zero and the user is informed of the fault condition.

44 Important Engineering Limitations

The following points must be treated as design-validation requirements rather than assumptions.

44.1 MOSFET Linear SOA

The BUZ11 headline current rating is not sufficient for this project because the MOSFET is used in its
linear region. The exact manufacturer’s forward-bias safe-operating-area curve must be checked at the
actual voltage-current operating point.

44.2 Thermal Rating

The 30 W peak value is a calculated electrical design point. The continuous rating depends on the actual
heatsink, airflow, ambient temperature, thermal interface, MOSFET package, and PCB arrangement.

44.3 Current Accuracy                                                  (150)
The nominal relationship

                                                           VSENSE ≈ I
is an ideal transfer. Real accuracy requires calibration.

44.4 Control-Loop Stability

The selected RC values are first-pass values. The completed circuit should be simulated and then
evaluated experimentally with an oscilloscope.

44.5 PCB Current Handling

A properly routed two-layer PCB is suitable for a 2 A current path, but the final trace width, copper
thickness, connector selection, via structure, and thermal rise must be checked against the final PCB
fabrication specification.

45 Conclusion

The proposed product is a programmable linear DC electronic load rather than a conventional fixed
resistor or manually adjusted rheostat. The key engineering function is to control the current absorbed
from an external DC source through a closed-loop power-semiconductor stage.
The first-pass architecture uses:

ESP32-WROOM-32 + MCP4725 + INA180A3 + LM358B + 4 × BUZ11 + Current Shunt + OLED
                                                                                                                             (151)

The principal electrical specifications are:                             (152)
                                                       VIN = 10 − −15 V

ILOAD,max = 2 A                                                          (153)

                                                      PLOAD,max = 30 W   (154)
and a practical constant-resistance emulation range of approximately

REQ ≈ 5 − −150 Ω                                                         (155)

subject to the simultaneous voltage, current, power, and thermal limits.

The two-layer PCB is feasible because the maximum load current is only 2 A. The dominant engineering
challenge is thermal dissipation and linear safe-operating-area verification of the MOSFET bank.

The design is intentionally structured so that the ESP32 is not the power converter. The ESP32 provides
user interaction, setpoint generation, measurement, protection logic, and test sequencing, while the
analog current loop performs the fast current control. This separation improves the power-electronics
content of the project and provides a clear academic basis for discussing semiconductor operation,
sensing, feedback control, thermal design, and PCB engineering.
